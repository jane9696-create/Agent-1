# Form Templates

Blank templates for Step 5 (form-filler) output. These are checked into the repo so every new session has them without needing a re-upload.

| File | Purpose |
|------|---------|
| `QSD_app_formEAnnex2_standard_mode_blank.odt` | QSD app form-E-Annex 2, standard mode. Blank template used as the base for filling in ISO 13485:2016 clause coverage (Procedure number, Version, etc.) during Step 5. |

## Usage

When dispatching Step 5, use this file as the blank template input instead of asking the user to re-upload it, unless the user says the template has changed (in which case replace this file and note the change here with a date).
